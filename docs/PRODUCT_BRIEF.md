# 제품 의도 브리프

마지막 확인: 2026-11-24

- 핵심 사용자: 건설 자재 구매 담당자(B2B)와 일반 소비자(B2C) 모두 (출처: 사용자 답변, 2026-11-09 질문 "이 앱의 핵심 사용자는 누구인가요?" → "둘 다")
- 왜 중요한지: 자재 구매 과정을 편리하게 하기 위해 (출처: 사용자 답변, 2026-11-08. 2026-11-23 사용자 요청으로 "견적 과정" 삭제: 웹 기준 기능 정렬, 견적을 1:1 문의로 대체)
- 가장 중요한 것: 빠르고 정확한 구매 — 반복 구매를 적은 단계로, 금액을 정확히 보여 주며 끝내는 것. 가격이 표시되지 않는 상품은 1:1 문의로 확인한다 (출처: 사용자 답변, 2026-11-09 질문 "이 앱에서 '가장 중요한 것'은 무엇인가요?". 2026-11-23 사용자 요청으로 "견적"을 "1:1 문의"로 대체: 웹 기준 기능 정렬)
- 포기할 수 있는 것: 실제 서비스(서버) 연동은 후속 작업으로 미룸. 같은 답의 "화면 이동"은 #27(PR #35, 2026-11-09)에서 연결 완료 (출처: 사용자 답변, 2026-11-08)
- 이렇게 한 이유: 디자인 방향은 제공된 Figma 기준으로 구현 (출처: 사용자 답변, 2026-11-08)

## 변경 이력
- 2026-11-08: 사용자 확인 후 최초 작성(원본 체크아웃의 미추적 파일). 핵심 사용자 "건설·시공 자재 구매자", 가장 중요한 것 "명확한 정보와 쉬운 조작".
- 2026-11-09: 핵심 사용자를 B2B·B2C 모두로, 가장 중요한 것을 "빠르고 정확한 구매·견적"으로 갱신(사용자 답변). 빈 3항목은 2026-11-08 답으로 채움(사용자 선택).
- 2026-11-17: 제품 의도 브리프 재확인(사용자 답변 "그대로 맞음"). 다섯 항목 변경 없음.
- 2026-11-23: 사용자 요청(웹 기준 기능 정렬, 견적 기능을 1:1 문의로 대체)에 따라 "왜 중요한지"와 "가장 중요한 것"에서 견적 표현을 삭제하고 가격 미표시 상품은 1:1 문의로 확인한다고 갱신. 나머지 항목은 재확인하지 않았고 "마지막 확인" 날짜는 그대로 둠.

- 2026-11-24: 제품 의도 브리프 재확인(사용자 답변 "그대로 맞음", 질문 "브리프가 아직 맞나요?"). 다섯 항목 변경 없음.
